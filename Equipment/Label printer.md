<a name = "Print"></a>
### <ins>Print labels</ins>

1. Navigate to the home tab
2. Click "Print" to open the printing settings page

<img width="1808" height="867" alt="label printer printing" src="https://github.com/user-attachments/assets/56e10dbb-497f-481b-9f67-e9f77a1a53a9" />

  - Use the checkmarks to select which labels you want to print. If you want to print multiple of each label, you can increase the number of copies. 
  - ***Tip: If you checkmark a single label, it will show you a preview to the right. Use this to make sure the longer labels will not bleed off the label when printing***
